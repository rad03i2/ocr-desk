# Changelog

All notable project changes are documented here.

## 1.0.0 — Initial release

### Added
- Local-first OCR command-line workflow.
- Support for PNG, JPEG, TIFF, BMP, and WebP image input.
- TXT, TSV, hOCR, and searchable PDF output.
- Single-language and multi-language recognition.
- Tesseract page-segmentation and engine-mode controls.
- Installed-language discovery command.
- JSON result output for scripts and automation.
- Explicit Tesseract executable selection.
- Safe output handling that avoids accidental overwrite by default.
- Automated tests and cross-platform continuous integration.
- Security, contribution, Arabic, and English documentation.

### Privacy
- No telemetry.
- No accounts.
- No API keys.
- No document uploads performed by OCR Desk itself.
