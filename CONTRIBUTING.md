# Contributing to OCR Desk

Thank you for helping improve OCR Desk. Contributions should stay focused, testable, privacy-conscious, and consistent with the local-first design of the project.

## Development setup

```bash
git clone https://github.com/rad03i2/ocr-desk.git
cd ocr-desk
python -m pip install -e .
```

## Before submitting a change

1. Create a focused branch for the change.
2. Keep behavior changes small and easy to review.
3. Add or update tests when behavior changes.
4. Run the full test suite.
5. Update documentation when user-facing behavior changes.
6. Never commit private scans, credentials, proprietary documents, or generated build artifacts.

Run tests with:

```bash
python -m unittest discover -s tests -v
```

## Pull requests

A good pull request should explain what changed, why it changed, and how it was tested. Keep unrelated changes out of the same pull request whenever possible.

## قبل إرسال أي تغيير

1. أنشئ فرعًا مخصصًا للتغيير.
2. اجعل التغيير محددًا وسهل المراجعة.
3. أضف اختبارًا عندما يتغير سلوك البرنامج.
4. شغّل جميع الاختبارات قبل إرسال طلب السحب.
5. حدّث التوثيق عندما يتغير شيء يراه المستخدم.
6. لا ترفع مستندات شخصية أو بيانات دخول أو ملفات خاصة أو مخرجات بناء مولدة.

لتشغيل الاختبارات:
