# Contributing / المساهمة

Thanks for improving OCR Desk. Keep changes focused, local-first, and covered by tests.

1. Fork the repository and create a feature branch.
2. Use Python 3.10+ and install with `python -m pip install -e .`.
3. Run `python -m unittest discover -s tests -v` before submitting.
4. Add tests for behavior changes and update both README language sections when user-facing behavior changes.
5. Never commit scans containing personal information, credentials, proprietary documents, or generated build artifacts.

مرحبًا بالمساهمات. اجعل التغييرات محددة وتحافظ على مبدأ المعالجة المحلية، وأضف اختبارًا لأي تغيير سلوكي. شغّل الاختبارات قبل فتح طلب السحب، ولا ترفع مستندات شخصية أو أسرارًا أو ملفات بناء مولدة.
